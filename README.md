# X-tracer

X-tracer は、X / Twitter のタイムラインで画面内に表示されたポスト URL を自動で保存し、あとから拡張機能ポップアップで一覧・検索・整理できる Chrome 拡張機能です。

## 主な機能

- タイムライン上で表示されたポストを自動保存
- 保存済みポストをポップアップから一覧表示
- URL・ユーザー名・本文プレビューで検索
- クリックで元ポストを新しいタブで開く
- 個別削除 / 全削除に対応
- 最大保存件数を設定可能（20〜2000件）
- 同じポストは重複保存しない
- データは `chrome.storage.local` にのみ保存

## UI の概要

### ポップアップ
- X-tracer ブランドのヘッダ
- 保存件数バッジ
- 検索バー
- 保存件数のクイック設定
- 保存済みポスト一覧
- 詳細設定画面への導線

### 設定画面
- 最大保存件数の設定
- 保存済みデータの全削除
- バージョンや保存方針の確認

## インストール方法

1. Chrome で `chrome://extensions` にアクセス
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このリポジトリのフォルダを選択
5. 拡張機能一覧に **X-tracer** が表示されれば完了

## 使い方

1. X または Twitter のタイムラインを開く
2. ポストが画面内に一定時間表示されると自動で保存される
3. 拡張機能アイコンから X-tracer のポップアップを開く
4. 保存済みポストを一覧・検索・開く・削除で管理する
5. 必要に応じて「詳細設定」から保存件数などを調整する

## 保存されるデータ

保存されるのは次の情報です。

- ポスト URL
- ポスト ID
- ユーザー名
- 本文プレビュー（短い抜粋）
- 保存日時

保存されないもの:

- 外部サーバーへの送信データ
- analytics / トラッキング情報
- クラウド同期用の独自データ

## プライバシー

- **ローカル保存のみ**: すべてのデータは `chrome.storage.local` に保存されます
- **外部送信なし**: 本拡張機能は外部サーバーへデータを送信しません
- **追跡なし**: 利用状況の収集は行いません

## 注意点

### X / Twitter 側の DOM 変更
X / Twitter の DOM 構造や URL 形式が変更されると、ポスト検知や保存処理が動作しなくなる可能性があります。

主な影響要因:

- X / Twitter の UI 改訂
- `article` 要素やリンク構造の変更
- ポスト URL 形式の変更

動作しない場合は、対象ページの DOM 構造を確認し、必要に応じて拡張機能を更新してください。
