# Twitter/X Tweet Saver

Twitter/X のタイムラインで表示されたツイートの URL を自動的に保存する Chrome 拡張機能です。

## 機能概要

- タイムライン上でツイートが画面に表示されたことを検知して自動保存
- 保存されたツイートの URL をポップアップ画面から一覧で確認
- クリックで該当ツイートを開く
- 最大保存件数を設定可能（20-2000件）
- 同じツイートは重複して保存されません
- 保存データはローカルの `chrome.storage.local` にのみ保存されます

## インストール方法

1. Chrome で `chrome://extensions` にアクセス
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリック
4. この拡張機能のフォルダを選択

## 使い方

1. Twitter や X のタイムラインを開く
2. ツイートが画面に表示されると自動的に保存されます
3. 拡張機能のアイコンをクリックしてポップアップを開く
4. 保存されたツイート一覧を確認し、「開く」ボタンでツイートを開けます
5. 必要に応じて、個別に「削除」または「すべて削除」で管理できます
6. 「最大保存件数」を変更して保存数を調整できます

### 設定画面

「設定」ボタン（またはオプション画面）から、以下の設定を変更できます:

- **最大保存件数**: タイムラインで保存するツイートの最大件数（デフォルト: 200件）

## 注意点

### Twitter/X の DOM 変更
Twitter/X の DOM 構造は頻繁に変更される可能性があります。以下の要因で拡張機能が動作しなくなる場合があります:

- Twitter/X の UI 改訂
- `article` 要素の構造変更
- ツイート URL の形式変更

動作しない場合は、開発者ツールで DOM 構造を確認し、必要に応じて拡張機能の更新を待つか、GitHub の issue で報告してください。

### 保存されるデータ
- **保存されるもの**: ツイート URL、保存日時
- **保存されないもの**: ツイート本文、ユーザー情報、他のメタデータ

## プライバシー

- **ローカル保存のみ**: すべてのデータは `chrome.storage.local` にローカル保存されます
- **外部送信なし**: 本拡張機能は外部サーバーへ一切データを送信しません
- **analytics なし**: 利用状況の収集は行いません
